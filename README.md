# Order Flow Imbalance (OFI) Feature Construction

This repository contains Python code for constructing Order Flow Imbalance (OFI) features from limit order book data, as part of the Trial Task assessment.

## Files

- `ofi_feature_construction.py` — Main Python script that calculates:
  - Best-Level OFI
  - Multi-Level OFI
  - Integrated OFI
- `first_25000_rows.csv` — Input dataset (provided separately).
- `ofi_features_output.csv` — Output file with timestamped OFI features.
- `OFI_Conceptual_Answers.tex` — LaTeX document answering the conceptual questions for Task 1.
